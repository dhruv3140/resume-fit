# ResumeFit - AI Resume Matcher

ResumeFit is a free online resume analysis tool that helps users compare their resume with a job description. It shows a match score, matched keywords, missing keywords, and improvement suggestions to make the resume more job-ready.

## Why I Built This

I built this because I regularly apply for internships and job opportunities, and I wanted a simple free tool to quickly check whether my resume matches a job description before applying.

## Features

* Upload resume in PDF, DOCX, or TXT format
* Paste any job description
* Automatic resume text extraction
* Live resume-job match score
* Matched keyword detection
* Missing keyword detection
* Personalized resume improvement suggestions
* Gemini AI powered resume coaching
* Copy suggestions button
* Responsive and modern UI
* Built for Digital Heroes button linked to https://digitalheroesco.com

## Tech Stack

* React.js
* Vite
* JavaScript
* CSS
* pdfjs-dist for PDF text extraction
* mammoth for DOCX text extraction
* Gemini API for AI suggestions
* Vercel for deployment
* GitHub for code hosting

## Database

This project does not use any database.

The uploaded resume and job description are processed temporarily in the browser and are not stored. This keeps the tool lightweight, fast, and simple to use.

## Project Type

This is a medium-level frontend project because it includes file upload handling, resume parsing, keyword matching logic, AI integration, responsive UI, and deployment.
