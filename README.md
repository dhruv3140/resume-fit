# ResumeFit - Smart Resume Matcher

ResumeFit is a free online resume analysis tool that compares a user's resume with a job description and shows a match score, matched keywords, missing keywords, and improvement suggestions.

## Why I built this

I built this because I often apply for internships and wanted a simple free tool to quickly check whether my resume matches a job description before applying.

## Features

- Upload resume in PDF, DOCX, or TXT format
- Paste job description
- Live match score
- Matched keywords
- Missing keywords
- Resume improvement suggestions
- Copy suggestions button
- Fully responsive UI
- Built for Digital Heroes button
